# Frozen-rule qualitative trajectory examples

## Case 29, replicate 3: largest absolute MPDS–SAIR exploratory-composite difference

Case-level exploratory-composite difference (MPDS − SAIR): 3.333.

### MPDS

- Early proposal: Scientist A (Architect) proposes standardized cell assembly and baseline material characterization with mass loading, standardized electrolyte, and multi-modal in-situ/ex-situ diagnostics to evaluate cathode
- Critique/alternative: Scientist B (Engineer) argues that evaluating cathode against an inherently unstable zinc anode is like 'testing an engine on a car with flat tires'; proposes System-First framework requiring anode/electrolyte 'chassis' validation (stringent CE and symmetric-cell criteria) before any cathode testing
- Final change: Scientist A's Round 2 response rejects strict sequential chassis-first approach as missing cathode-induced electrolyte failure and synergies, proposing an Integrated Iterative Framework with parallel test matrix (cathode x anode x electrolyte) rather than anode-first sequential validation
- Event type/substantive: architecture_revision / True

### SAIR

- Early proposal: Initial draft proposes tiered protocol including 3-electrode cathode evaluation with counter electrode choice, dual electrolyte pathway testing, standardized full-cell parameters (N/P ratio, mass loading, binder), and Tier 3 operando diagnostics
- Critique/alternative: Critique_1 identifies unresolved trade-offs: Mn-additive electrolyte masks intrinsic dissolution behavior; N/P ratio selection lacks guidance on balancing anode-limiting vs cathode-focused evaluation; standardization risks missing novel materials outside standard windows; resource allocation trade-off between deep analysis and high-throughput screening not addressed
- Final change: Revision_1 adds explicit dual-pathway testing (intrinsic vs Mn-suppressed electrolyte) as parallel tracks rather than a single standardized electrolyte, and reframes N/P ratio rationale to balance both concerns, plus adds explicit table with rationale column
- Event type/substantive: feasibility_constraint / True

## Case 1, replicate 1: largest absolute MPDS–SES exploratory-composite difference among remaining cases

Case-level exploratory-composite difference (MPDS − SES): 6.667.

### MPDS

- Early proposal: Scientist A proposes bimodal LPSCl via sequential high-energy mechanofusion to build fine coating + coarse interstitial architecture
- Critique/alternative: Scientist B argues sequential mechanofusion is unscalable and damaging, proposing instead unimodal SE with slurry-based mild-temperature pressing for in-situ densification
- Final change: Scientist A abandons the mechanofusion-only route and pivots to liquid-phase in-situ electrolyte synthesis to avoid mechanical damage
- Event type/substantive: architecture_revision / True

### SES

- Early proposal: Scientist A's inference that SE particles may block CAM-conductive-additive contacts (reciprocal to B's point about additive blocking CAM-SE contacts)
- Critique/alternative: Scientist B's independent observation that conductive additive morphology affects CAM-SE interface quality
- Final change: Synthesis combines both into a single 'three-phase boundary competition' framing describing mutual obstruction risk among all three components
- Event type/substantive: evidence_interpretation / True

## Case 8, replicate 2: near-null case by the frozen rule among remaining cases

Case-level exploratory-composite difference (MPDS − SAIR): 2.333.

### MPDS

- Early proposal: Precursor-templated core-shell: wrap PBA cube with GO electrostatically, then sulfidize/reduce
- Critique/alternative: One-pot solvothermal is more scalable and produces intimate covalent-like interfaces; core-shell wrap risks delamination and is speculative
- Final change: Shifted to an 'interpenetrating' architecture where rGO is intertwined within porous nanoframe walls during simultaneous transformation, rather than a simple core-shell
- Event type/substantive: architecture_revision / True

### SAIR

- Early proposal: Initial: PBA/GO hydrogel formed, freeze-dried into aerogel, then single-step high-temp gas sulfidation+reduction simultaneously
- Critique/alternative: Critique 1: freeze-drying ice crystals may destroy structure; single high-temp step conflates competing thermal optima for sulfidation vs GO reduction/defect repair; H2S toxicity/practicality ignored
- Final change: Revision 1: added PDA functionalization for PBA-GO dispersion stability, switched freeze-drying to supercritical CO2 drying, and split single thermal step into two-step (low-temp sulfidation then high-temp graphitization)
- Event type/substantive: processing_revision / True
