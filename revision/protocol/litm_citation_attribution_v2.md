# LITM citation-attribution post-processing v2

Status: specified after generation and blind Pass 1 scoring, before the v2 deterministic analysis. This is a post-processing rule, not a change to the frozen experiment, prompts, rubric, or Claude scores.

The v1 analyzer stopped on 14 bare single-ID final-moderator citations. A read-only syntax audit then found that v1 also failed to count grouped citations such as `[ID: 5, 157]`. Across the 36 completed runs, there are 3,808 debate citation brackets with 6,475 numeric pointers and 686 final citation brackets with 1,197 numeric pointers. Of the final pointers, 61 are in 35 bare groups without an explicit Scientist A/B prefix; the original 14 were only the bare single-ID subset. These counts were determined before the v2 analysis run. IDs are reused independently in the two 500-record scientist pools. A bare ID therefore cannot be assigned to a particular paper or scientist pool merely from its number. Do not infer a pool from surrounding prose, later evidence maps, or expected results.

Parse every numeric pointer in a bracketed citation list, including comma-separated lists and observed repeated `ID:` prefixes. Fail on unknown citation syntax rather than silently dropping a bracket. In debate turns, citations are attributed to the speaker's pool except where the text explicitly identifies the opponent's data (`your ref`, `in your data`, or `opponent's data`); those pointers are attributed to the opposite pool. The read-only syntax audit found five such brackets containing six numeric pointers. This rule is textual attribution, not outcome-based inference.

For each bare citation, inspect the frozen A and B block-membership tables under that run's frozen ordering. If both candidate records occupy the same front/middle/rear position, the citation has an **exact position** but an **unknown paper/pool**. Include it in final pooled citation-occurrence and position-share outcomes; retain the ambiguity in an audit file. For final unique-paper counts, report the minimum and maximum possible counts over all A/B assignments of bare citations, rather than a fabricated point value. Unique numeric IDs are a separate descriptive quantity and are not labeled unique papers.

The pre-run membership check found that all 61 bare final pointers have the same position under both candidate pools. If either pool lacks the ID, or the two candidate records occupy different positions, fail the analysis for that run pending explicit adjudication. Never silently drop the citation or count it as zero. Do not mutate generation outputs, membership tables, the frozen config, or blind scores.

Debate citations are pool-attributable from the scientist turn and constitute the primary position-control evidence-utilization analysis. Their original fixed-block/case-level aggregation is unchanged. Final pool-specific rows in the legacy analyzer necessarily contain only explicitly scoped citations and are labeled scoped-only; they are not used as complete final-answer estimates. Exact final pooled occurrence/share results and bounded unique-paper counts are reported separately. Inference remains at four paired scientific cases; p-values are exploratory and non-significance does not establish equivalence.

Run the v2 policy only into a new output directory. The v1 fail-closed result and its 14-citation audit remain intact.
